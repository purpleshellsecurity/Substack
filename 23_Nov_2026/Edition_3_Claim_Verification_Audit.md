## Corrections applied in the revised draft

1. Azure Firewall AI Security explicitly identified as **public preview** and scope-qualified.
2. Agent Grid described as **public preview with limited supported runtimes**, rather than implying unrestricted availability.
3. Added Azure Adaptive Virtual Patching and explicitly distinguished mitigations from software patching.
4. Added Azure Policy Enrollments, IP filtering, Machine Inventory and Arc Configuration Manager integration with their previews/limitations.
5. Added Key Vault symmetric AES and Azure SQL TDE AES protectors, each **GA**, without implying post-quantum cryptographic guarantees.
6. Added DocumentDB granular RBAC, HorizonDB feature-level status and SQL MI changes separately.
7. Separated core Azure Infrastructure Resiliency Manager **GA** from **preview Resiliency Agent**.
8. Split Azure Backup vault protection from **preview** Safe Restore, cross-tenant restore, threat detection and Region of Choice; deleted unsupported impression that source-alert scanning certifies backup cleanliness.
9. Expanded DDoS, Network Watcher, network security perimeters, AKS boot and confidential disk hardening.
10. Updated confidential compute paragraph so the Book of News previews are not mislabeled universally as future-only engineering.
11. Tracked contradictory product-team previews for Chaos Studio AKS and PostgreSQL PITR while retaining the author's Book-of-News-based GA wording.

## Publication checks and remaining limits

- **Factual documentation:** 59 grouped claims have a Microsoft primary source and an attributed status/feature description in the source register. Direct search/open checks during this pass confirmed key adaptive patching, Azure BSM, APIM, backup, Book of News, DDoS, cryptography, Network Watcher and AKS records. Other cited claims rely on the previously assembled source reconciliation, not a fresh page-by-page re-fetch of every link in this call.
- **Source conflicts remain exactly two central event-classification disputes:** Chaos Studio AKS extension and PostgreSQL immutable PITR. Do not describe them as independently resolved just because the newsletter uses the Book of News.
- **Potential wording nuance:** Azure BSM M365-versus-Azure preview disagreement is documented separately in the draft and verified inventory. Do not state tenant eligibility as fact.
- **Publication blocker outside facts:** The Engineer's Assessment is a proposal that needs authorial review. Edition 2 public link remains a placeholder in the narrative (Part 2 has no verified public URL). The article is saved in GitHub and **not published**.
- **Coverage:** The full Azure Updates listing could not be paginated; this is a grounded editorial technical review, not a certified census of every Azure release.

**Audit decision:** Suitable for **editorial review** with transparent release-status attribution and clear feature limitations. Do not characterize it as comprehensive deployability testing or as an exhaustive Azure-release catalogue.
