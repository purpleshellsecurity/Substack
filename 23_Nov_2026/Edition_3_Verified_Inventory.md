## Additional reconciliation update — backup and SQL

- [Azure Backup security overview](https://learn.microsoft.com/en-us/azure/backup/security-overview) published/updated November 17 explicitly labels Defender-backed recovery point threat detection, cross-tenant restore and Azure VM bulk Safe Restore as **preview**. Threat detection is alert-driven using the source VM and must not be represented as a malware scan of the stored backup or proof of clean recovery points.
- [Cross-tenant restore preview documentation](https://learn.microsoft.com/en-us/azure/backup/cross-tenant-restore-overview) limits support to vaulted recovery points, requires mapping before tenant lockout, and has workload/region restrictions. Backup vaults: West Europe, North Europe, East US, UK South, Australia East/Southeast and Brazil South per November 17 documentation.
- [Dedicated MI link GA announcement](https://techcommunity.microsoft.com/blog/azuresqlblog/mi-link-support-for-multiple-databases-in-an-always-on-availability-group-is-now/4571052) confirms multi-database mode **GA November 17**. The SSMS multi-node wizard remains preview.

## Editorial omissions and deduplication decisions

- **Edition 1 overlap:** AKS agent sandbox and agent governance covered at length in AI/agent security edition; Edition 3 should focus on network enforcement and infrastructure prerequisites.
- **Edition 2 overlap:** Windows 365 conditional resource redirection and M365 baseline GA are already in the SOC/identity edition; Azure-specific baseline deserves separate Edition 3 coverage.
- **Database security:** DocumentDB granular RBAC, Postgres immutable backups and SQL MI zone redundancy are actual infrastructure security/resilience releases. The original Edition 3 article gives them insufficient coverage. Add them *after* verification, not before.
- **Mere platform capabilities:** HorizonDB private endpoint/Entra/CMK support can be mentioned as documented service controls but should not be marketed as separate Ignite feature launches without date-specific evidence.
- **Preview/future concepts:** Confidential child-capable VM, new enclave models, and next-generation confidential containers described as future engineering do not count as available previews.

## Resolved publication blockers and scope decisions

1. **Backup: CLOSED for editorial reporting.** Region of Choice is **preview** ([November 17 first-party article](https://techcommunity.microsoft.com/blog/reliability-and-resiliency-in-azure/beyond-availability-zones---building-resilience-across-regions-with-azure/4573795)). VM Safe Restore bulk, threat detection and cross-tenant restore are individually preview; vault protections are existing configuration-dependent controls, not a new blanket GA product. No universal supported-workload claim.
2. **SQL: CLOSED.** Zone redundancy and multi-database MI link GA independently verified; SSMS wizard preview.
3. **Windows Server: CLOSED by splitting dates/status.** Windows Server 2028 public preview and Hardened Server Core Insider preview. Trusted Launch Insider implementation from July 2026; PQC TLS implementation in October, while composite certificates have future timing. Do not misrepresent them as new November GA features.
4. **Azure governance: CLOSED by first-party feature-specific classification below.** Distinguish September/July prior announcements from November material.
5. **Completeness limitation:** This is a *closed editorial evidence review for identified substantive findings*, not a formal exhaustive Azure Updates census, independent tenant QA or verification of every product-region combination. No source proves every relevant update was collected. Maintain this explicit limitation rather than indefinitely blocking publication.
