# LinkedIn post: Ignite 2026 Edition 3

Microsoft is adding more control and visibility over AI workloads at the Azure infrastructure level.

The final part of my Ignite 2026 coverage looks at Azure Firewall AI Security, Agent Grid, and the broader updates to security baselines, encryption, workload protection, and recovery.

From a security engineering standpoint, understanding the systems behind these controls still matters. Knowing that an agent connected to a service is a starting point. We also need to know what that service does, what data it handles, and how the agent is supposed to use it.

That context helps us understand whether the activity is expected and where controls need to be applied.
